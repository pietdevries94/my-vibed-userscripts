# my-vibed-userscripts

Violentmonkey userscripts, one per website. Install a script by opening its install link in a browser with Violentmonkey. Violentmonkey checks for updates on its own.

## Scripts

<!-- scripts:start -->

- **Fix Azure DevOps** 1.0.0: Adds missing features to Azure DevOps. Shows the pipeline status of each pull request in the list. [Install](https://raw.githubusercontent.com/pietdevries94/my-vibed-userscripts/main/dist/azure-devops.user.js)
- **Fix Tweakers** 1.0.0: Trims Tweakers. Shows only the news item list on the homepage. [Install](https://raw.githubusercontent.com/pietdevries94/my-vibed-userscripts/main/dist/tweakers.user.js)

<!-- scripts:end -->
